It helps to address heavy conversations where otherwise often leads to being defensive.

---
#### Avoid using this method to these situations:

1. Affairs
2. Addictions
3. Other sensitive topic.

Ideal for alignment and accountability issues.

---
#### Practice

1. KISS
	1. Start with something affirming, positive, kind, positive.
	2. *Hey, I really see how you... I want to appreciate you for...*
2. KICK
	1. Don't say "you". Use "we" language.
	2. Start with an I: "*I noticed that...*"
	3. Make sure that you make it about you or your needs/expectations.
	4. The actual core criticism or hard truth.
3. KISS
	1. Give grace, remind cooperation between each other.
	2. Remind them that you're doing this out of love and respect for each other.
	3. *I'm saying/doing this because I love you.*
	4. Make him believe that you can figure it out together.
